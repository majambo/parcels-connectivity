# parcels-connectivity
This project models dispersal patterns of four fish species larvae (Cryptobenthic, Parental, Resident, and Transient) in marine environments using Parcels (Probably A Really Computationally Efficient Lagrangian Simulator), a Python framework designed for particle tracking simulations with Ocean Circulation model outputs.
The simulations rely on oceanographic data from WINDS-M (Western Indian Ocean Simulation, Multidecadal), a high-resolution regional ocean simulation covering the SW Indian Ocean from 1993-2020. WINDS-M operates at 1/50° horizontal resolution using the Coastal and Regional Ocean Community model (CROCO). It incorporates multiple data sources: daily lateral boundary data from the 1/12° CMEMS GLORYS12V1 global ocean reanalysis, barotropic tides from TPXO9, hourly surface data from ERA5, and climatological river inputs.
The simulations track larvae from their release at coral reef habitats through their pelagic larval duration (PLD) until potential settlement at new locations. The models incorporate species-specific parameters including egg type, PLD variations, and release timing.
Project outputs include raw trajectory files, processed connectivity metrics, and visualizations that help researchers analyze dispersal patterns, settlement success rates, and network connectivity between different reef habitats across the region.
